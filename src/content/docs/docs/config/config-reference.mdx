Hive reads `~/.config/hive/config.toml` (`%APPDATA%\Hive\config.toml` on Windows), or `$XDG_CONFIG_HOME/hive/config.toml`, or the explicit file in `$HIVE_CONFIG`. All settings are optional. Run `hive config default` to print the defaults, `hive config init` to write a commented file, and `hive config validate` to check the current config.

Invalid values and unknown keys produce warnings and use defaults. Invalid TOML prevents the daemon from starting. Runtime data lives under `~/.hive` by default (`%LOCALAPPDATA%\Hive` on Windows); set `HIVE_HOME` to use another root.

## Daemon and logs

| Section and key | Default | Description |
| --- | --- | --- |
| `[daemon].autostart` | `true` | Start the daemon when a command needs it. |
| `[daemon].shutdown_timeout` | `"15s"` | How long stopping waits for agents to exit. |
| `[log].level` | `"info"` | `debug`, `info`, `warn`, or `error`; `HIVE_LOG` overrides this. |
| `[log].format` | `"text"` | `text` or `json`. |
| `[log].max_size_mb` | `10` | Daemon log rotation size. |
| `[log].max_backups` | `3` | Number of old daemon logs to keep. |
| `[process].stop_grace` | `"3s"` | Time an agent gets to exit after `SIGTERM` (on Windows, after its pseudo console closes) before Hive kills it. |

## Terminals and Git

| Section and key | Default | Description |
| --- | --- | --- |
| `[terminal].default_width` | `220` | Width of a new agent terminal when unspecified. |
| `[terminal].default_height` | `50` | Height of a new agent terminal when unspecified. |
| `[terminal].scrollback_mb` | `10` | Scrollback retained per agent terminal, in MiB. |
| `[terminal].shell` | `""` | Shell for a new pane; empty uses `$SHELL -l`. On Windows, empty uses `$SHELL`, then `pwsh`, Windows PowerShell, or `%ComSpec%`. |
| `[git].refresh_interval` | `"5s"` | How often Hive refreshes environment branch and dirty state. |
| `[worktrees].directory` | `""` | Worktree base directory; empty uses `~/.hive/worktrees` (or `$HIVE_HOME/worktrees`). |

## Sessions and retention

| Section and key | Default | Description |
| --- | --- | --- |
| `[session].restore` | `true` | Restore lost panes, layout, and focus after a host reboot or shim loss. |
| `[session].resume_agents_on_restore` | `true` | Resume supported agents' conversations; when false, restored agents start fresh. |
| `[session].restore_stagger` | `"1s"` | Pause between restarting agents. |
| `[session].snapshot_interval` | `"30s"` | Periodic workspace snapshot interval. Changes are also saved as they occur. |
| `[session].keep_snapshots` | `48` | Number of previous snapshots to retain. |
| `[session].replay_history` | `false` | Save recent pane text and show it after restore. This can include secrets printed by a program. |
| `[session].replay_lines` | `500` | Number of recent lines to keep when replay is enabled. |
| `[retention].exited_processes` | `"168h0m0s"` | How long to keep records/logs of exited processes not shown in a pane. |
| `[retention].process_log_mb` | `50` | Per-agent output log size before rotation; one older log is kept. `0` disables the limit. |
| `[retention].gc_interval` | `"6h0m0s"` | Automatic cleanup interval; `"0s"` disables scheduled cleanup. |

## Updates and remote machines

| Section and key | Default | Description |
| --- | --- | --- |
| `[update].channel` | `"stable"` | Update channel: `stable` or `preview` (release candidates). |
| `[remote].ssh` | `"ssh"` | SSH command used for remote Hive; `HIVE_SSH` overrides it. OpenSSH config applies. |
| `[remote].frame_budget_kb` | `48` | Approximate screen data limit per remote client, in KiB/s; `0` means unlimited. |
| `[remote].image_budget_kb` | `1024` | Upload rate for pasted images sent to a remote daemon, in KiB/s; `0` means unlimited. Keystrokes typed meanwhile go between its pieces. |

## Images

| Section and key | Default | Description |
| --- | --- | --- |
| `[images].max_kb` | `5120` | Largest image pasted with <kbd>Ctrl</kbd>+<kbd>B</kbd>, then <kbd>I</kbd>, in KiB (hard cap 16 MiB). The UI and the daemon each apply their own value. |
| `[images].max_megapixels` | `16` | Most pixels a pasted image may have, in megapixels (hard cap 64). |
| `[images].keep` | `"1h0m0s"` | How long images saved for agents that take a file path (Claude Code, Codex) are kept. `"0s"` never saves, so such agents refuse images. |
| `[images].log_graphics` | `false` | Keep images agents print (Kitty graphics) in their output logs. Off strips them so image data never reaches disk. |
| `[images].render` | `"auto"` | How printed images are drawn: `auto` (Kitty, iTerm2, or Sixel as the terminal supports, else coloured cells), `cells`, `text`, or `off`. |

See [Images and Terminal Graphics](/docs/use/images/).

## Plugins

| Section and key | Default | Description |
| --- | --- | --- |
| `[plugins].allow` | `[]` | Capabilities granted without asking to plugins that list them as optional: `hive.read`, `hive.write`, `hive.input`, `hive.process`, `hive.admin`, `filesystem.write`, `network`, `process.exec`. |
| `[plugins].deny` | `[]` | Capabilities no plugin gets. A plugin that requires a denied capability does not run. |
| `[plugins].isolation` | `"auto"` | `auto` sandboxes plugins that declare `isolation = "strict"`; `standard` never sandboxes; `strict` sandboxes every plugin (needs `sandbox-exec` on macOS or `bwrap` on Linux, otherwise none run). |
| `[plugins].restart_limit` | `5` | A plugin command that fails more than this many times within `restart_window` is no longer restarted. `hive plugin reload <id>` resets it. |
| `[plugins].restart_window` | `"10m0s"` | Window for `restart_limit`. |
| `[plugins].hidden` | `[]` | Contributions to turn off: `"plugin"`, `"plugin:kind"`, or `"plugin:kind:id"`. `hive plugin contributions` lists them. |

See [Plugin API v1](/docs/config/plugin-api/).

## Observers and the web observer

| Section and key | Default | Description |
| --- | --- | --- |
| `[observers].enabled` | `true` | Serve the read-only observer socket for credential holders (`hive observer create`). Off, nobody can observe. |
| `[observers].history_events` | `2048` | Events kept for observers to catch up with after a reconnect (64 to 100000). |
| `[observers].max_connections` | `32` | Open observer connections allowed, all credentials together. |
| `[web].listen` | `"127.0.0.1:8484"` | HTTP address of the web observer (`hive web serve`). Beyond loopback it needs TLS or a proxy that terminates it. |
| `[web].public_url` | `""` | Where browsers reach it, for share links; empty derives it from `listen`. |
| `[web].tls_cert`, `[web].tls_key` | `""` | Certificate and key to serve HTTPS. |
| `[web].behind_proxy` | `false` | A reverse proxy in front terminates TLS; cookies are then Secure. |
| `[web].push` | `true` | Web Push notifications for phones and browsers that turn them on (HTTPS or localhost only). |
| `[web].push_contact` | `""` | `mailto:` or `https:` contact for push services; empty uses the public URL. |
| `[web].push_allow_any_endpoint` | `false` | Accept push services other than the browsers' own (Google, Mozilla, Apple, Microsoft). |

See [Observers](/docs/use/observers/), [Web Observer](/docs/use/web-observer/), and [Hive on Your Phone](/docs/use/mobile/).

## Notifications

| Section and key | Default | Description |
| --- | --- | --- |
| `[notify].on` | `["blocked", "done"]` | Agent states that produce notifications. |
| `[notify].toast` | `true` | Show a toast in the Hive UI. |
| `[notify].terminal` | `"auto"` | Terminal notification mode: `auto`, `osc9`, `osc777`, or `off`. |
| `[notify].system` | `false` | Use desktop notifications; these do not work over SSH. |
| `[notify].sound` | `false` | Play a sound with notifications. |

Choose notification states per agent manifest ID:

```toml
[notify.agents]
codex = ["blocked"]
aider = []
```

Notifications are suppressed for the pane you are currently viewing.

## User interface and theme

| Section and key | Default | Description |
| --- | --- | --- |
| `[ui].sidebar` | `true` | Show the environment/agent sidebar. Very narrow terminals open without it. |
| `[ui].sidebar_width` | `28` | Sidebar width in terminal columns. |
| `[ui].mouse` | `true` | Enable mouse focus, resize, selection, and scrollback. Hold Shift to pass selection to the outer terminal. |
| `[ui].clipboard` | `"auto"` | Copy destination: `auto`, `osc52`, `local`, or `off`. |
| `[theme].name` | `"auto"` | Theme: `auto`, `catppuccin`, `catppuccin-latte`, `tokyo-night`, `gruvbox`, `nord`, `terminal`, or `custom`. |

`auto` selects a dark or light theme based on the terminal background. With `name = "custom"`, override individual colors:

```toml
[theme.custom]
base = "nord"
accent = "#ff79c6"
```

Custom colors can be `#rrggbb`, an ANSI index from `0` to `255`, or `"default"`.

The tab bar can show text, a date/time, the host name, or a command's first line:

```toml
[[ui.status_right]]
type = "command"
command = "git -C ~/src/app branch --show-current"
interval = "30s"

[[ui.status_right]]
type = "datetime"
format = "%a %H:%M"
```

## Keys

`[keys].prefix_keys` defaults to `["ctrl+b"]`. Multiple prefix keys are allowed. Bind actions in `[keys.prefix]`, `[keys.terminal]`, `[keys.navigate]`, `[keys.resize]`, and `[keys.copy]`. Terminal bindings run without a prefix. Each action accepts one key or a list; an empty list unbinds it.

```toml
[keys]
prefix_keys = ["ctrl+b", "ctrl+a"]

[keys.prefix]
split_right = ["|", "%"]
zoom = []

[keys.terminal]
focus_left = "alt+h"
```

Keys can also run custom commands. See [Plugins and Key Commands](/docs/config/plugins/) for the command types and examples. Run `hive config reset-keys` to restore built-in keybindings without replacing other configuration.
