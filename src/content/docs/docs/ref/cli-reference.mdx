The `hive` command opens the multiplexer when run without a subcommand. Commands that need the runtime start the daemon automatically unless `daemon.autostart` is disabled.

Run `hive --help` or `hive <command> --help` to see the options supported by your installed release.

## Global options and output

| Option | Purpose |
| --- | --- |
| `--json` | Print machine-readable JSON. |
| `--template '<template>'` | Format command output with a Go template. |
| `--session <name>` | Select a named local session. |
| `--remote <host>` | Run the command against a Hive daemon reached over SSH. |
| `--machine <name>` | Use a saved remote machine. |
| `--yes` | Accept supported confirmation prompts in automation. |

Examples:

```sh
hive --json agent list
hive env list --template '{{range .}}{{.id}} {{.path}}{{"\n"}}{{end}}'
hive --remote build-box agent list
```

## Environments and worktrees

| Command | Purpose |
| --- | --- |
| `hive env list` | List environments. |
| `hive env create <id> --cwd <path>` | Create an environment at an existing directory. |
| `hive env get <id>` | Inspect an environment. |
| `hive env rm <id>` | Remove an environment and stop its agents. |
| `hive worktree create <branch>` | Create a worktree for isolated agent work. |
| `hive worktree list` | List worktrees. |
| `hive worktree open <branch>` | Open an existing worktree in Hive. |

## Agents and processes

| Command | Purpose |
| --- | --- |
| `hive agent list` | List recognized agents and their states. |
| `hive agent get <agent>` | Inspect an agent. |
| `hive agent explain <agent>` | Show why Hive assigned its current state. |
| `hive agent start --kind <kind> --env <env>` | Start an agent in a new tab. Add `--worktree <branch>` for an isolated checkout. |
| `hive agent prompt <agent> <text> [--wait] [--read N]` | Send a prompt; optionally wait and print recent output. |
| `hive agent wait <agent> --until idle\|done` | Wait for an agent state. |
| `hive agent read <agent>` | Read terminal output. |
| `hive agent stop <agent>` | Stop an agent. |
| `hive ps list` | List running and recorded processes. |
| `hive ps logs <id> [-n N] [-f] [--stderr]` | Read or follow process output logs. |
| `hive terminal attach <id>` | Attach directly to an agent terminal; <kbd>Ctrl</kbd>+<kbd>]</kbd> detaches. |
| `hive terminal snapshot <id> [--scrollback N]` | Print a terminal's current screen and optional history. |

## Plans, branches, and issues

| Command | Purpose |
| --- | --- |
| `hive task run [plan.toml \| -]` | Run a plan file, or one task given by flags. `--from-issue <tracker:key>` starts a task from an issue. |
| `hive task list\|get\|report` | List plans, show a plan or one task, and print what a plan did. |
| `hive task wait <plan> [task] [--until attention]` | Wait for a plan or task to finish, or to need you. |
| `hive task approve\|cancel\|retry <plan> [task]` | Approve a waiting task (`--deny` cancels it), cancel work, or run failed and skipped tasks again. |
| `hive branch list\|get\|check` | List the branches Hive follows, show one, or read them again now. |
| `hive branch diff\|conflicts <branch>` | Show a branch's changes, or what merging it would conflict on. |
| `hive branch comment\|send <branch>` | Add review comments and send them back to the branch's agent. |
| `hive branch ready <branch>` | Run the branch's gates; it is ready when they pass. |
| `hive branch update\|push\|pr\|clean` | Merge the base in, push, open a pull request, or remove merged worktrees. |
| `hive issue get\|search\|comment\|close` | Read and update issues in GitHub and plugins' trackers (`github:owner/repo#42`). |

See [Plans and Tasks](/docs/use/plans/) and [Branches](/docs/use/branches/).

## Workflows

| Command | Purpose |
| --- | --- |
| `hive workflow list\|show <name>` | List workflow files with their triggers and latest runs, or show one. |
| `hive workflow validate <file \| ->` | Check a workflow file without running it (no daemon needed). |
| `hive workflow run <name \| file.toml> [-i key=value] [--wait]` | Run a workflow. `--headless --json` runs it in CI with a daemon of its own. |
| `hive workflow runs\|status\|wait\|report <run>` | List runs, follow one, and print its report. |
| `hive workflow cancel\|rerun <run>` | Stop a run, or run it again with the same text, inputs, and trigger. |
| `hive workflow fire <webhook>` | Fire the workflows whose webhook trigger has this name. |
| `hive workflow trust <name>` | Let a shared workflow's triggers fire. |
| `hive workflow reload` | Read the workflow files again. |

See [Workflows](/docs/use/workflows/).

## Insights and budgets

| Command | Purpose |
| --- | --- |
| `hive insights [--since 7d] [--by kind\|agent\|environment\|task\|day\|model]` | Show agents' time in each state, and the tokens and cost they reported. |
| `hive insights asks` | List the times agents waited on you, and what they asked. |
| `hive insights budgets` | Show each budget's use of its limits, and what it holds. |
| `hive insights resume <budget> [key]` | Let new tasks start again under a budget that holds them. |
| `hive insights export --what spans\|usage\|alerts\|summary --format csv\|json` | Write insights out. |
| `hive insights report\|statusline` | Report an agent's usage from a script, or as Claude Code's status line. |

See [Insights and Budgets](/docs/use/insights/).

## Teams

| Command | Purpose |
| --- | --- |
| `hive access invite <name> --key <file> --role <role> (--env <id>… \| --all)` | Let a teammate in over ssh with a role. |
| `hive access list\|show\|grant\|renew\|revoke` | Manage members, their roles, and their expiry. |
| `hive access audit\|doctor\|whoami` | Read the audit log, check `authorized_keys`, and show who a connection is. |
| `hive presence` | Show who is connected, where they are looking, and who is typing where. |
| `hive pane claim\|release [pane]` | Take a pane's input (`--force` to take it from someone), or let it go. |
| `hive agent handover [agent] <member>` | Give an agent, its task, and its pane's input to another member. |
| `hive task assign <plan> [task] --to <member>` | Give a task, or a plan and its unfinished tasks, to another member. |

See [Teams](/docs/use/teams/).

## Runtime and session

| Command | Purpose |
| --- | --- |
| `hive status`, `hive ping`, `hive version` | Check Hive and the daemon version/status. |
| `hive daemon start\|stop\|status\|logs` | Manage the background daemon. |
| `hive daemon restart` | Restart the daemon while agent shims keep running. |
| `hive daemon install\|uninstall` | Install or remove the login service (launchd on macOS, systemd user service on Linux, Task Scheduler on Windows). |
| `hive session save` | Save a workspace snapshot now. |
| `hive session restore [--fresh]` | Restore panes that were lost. `--fresh` starts agents without resuming their prior conversation. |
| `hive stop` | Stop the runtime and all agents it manages. |
| `hive gc [--dry-run] [--older-than <duration>]` | Remove old records and leftover data; dry run previews cleanup. |
| `hive update [--check] [--version <tag>] [--channel stable\|preview]` | Check for or install an update. |
| `hive update --rollback` | Restore the previous binary; run it again to undo. |

| `hive plugin views\|click` | List plugins' pane views or draw one as text, and press a view's button. Open one with `hive pane split --view`. |
| `hive plugin export\|import` | Back up and restore plugin sources, grants, settings, and optionally data. |
| `hive plugin card\|status\|ready\|request\|view\|trigger` | Called from plugin scripts to set cards and indicators, report readiness, ask for a capability, set a pane view, or fire a workflow trigger. |
| `hive machine add\|list\|status\|reconnect\|remove\|rename\|set` | Save and manage SSH destinations, and the labels tasks are placed by. |
| `hive machine discover\|pair\|trust\|identity\|revoke` | Find runtimes on the local network and pair with them. See [Local Discovery](/docs/use/discovery/). |
| `hive debug stats` | Print daemon runtime statistics. |
| `hive debug pprof [--profile <name>] [--seconds N] [-o <file>]` | Capture a runtime profile for performance investigation. |

## Observers and the web observer

| Command | Purpose |
| --- | --- |
| `hive observer create <name> (--all\|--env <id>…\|--pane <id>…) [--screens] [--expires <d>]` | Create a scoped, expiring, read-only credential; prints the token once. |
| `hive observer list\|show\|revoke\|validate\|audit` | Manage credentials and read the observer audit log. |
| `hive observer status\|snapshot\|screen\|watch\|events` | Act as an observer with the token in `$HIVE_OBSERVER_TOKEN` or `--token-file`. |
| `hive proxy --observer` | Bridge stdin/stdout to the observer socket, for SSH-restricted observers. |
| `hive web runtime add\|list\|remove` | Allow the web observer to show a runtime (this session, `--remote`, or `--machine`). |
| `hive web serve [--listen] [--public-url] [--tls-cert --tls-key] [--behind-proxy]` | Run the web observer. |
| `hive web share [--runtime <name>] [--screens] [--history] [--expires 8h] [--uses 1]` | Create a one-time browser sign-in link. |
| `hive web grants\|revoke\|audit\|status` | See who is signed in, end access, read the audit log, and check runtime connections. |
| `hive web push status\|test` | List notification devices and send a test notification. |

See [Observers](/docs/use/observers/), [Web Observer](/docs/use/web-observer/), and [Hive on Your Phone](/docs/use/mobile/).

## Exit statuses

Hive uses `0` for success, `1` for a runtime error, `2` for invalid command-line usage, and `3` when a command requires a daemon that is not running. Agent wait commands also use `4` for timeout and `5` when an agent blocks, stalls, or exits before the requested state.

For API calls outside the CLI, see [Socket API](/docs/ref/socket-api/). For task workflows, see [Orchestration](/docs/use/ai-orchestration/).
