Hive works with the mouse and keyboard. Click a pane to focus it, drag its border to resize it, or select text to copy. Keyboard shortcuts let you move between panes and tabs without leaving the keyboard.

## How the prefix works

Hive reserves a prefix so its shortcuts do not take over keys used by your shell or agent. The default prefix is <kbd>Ctrl</kbd>+<kbd>B</kbd>. Press and release it, then press the action key. For example, <kbd>Ctrl</kbd>+<kbd>B</kbd>, then <kbd>c</kbd> creates a tab.

When you are not entering a Hive shortcut, keystrokes go to the focused pane as usual. Press <kbd>Ctrl</kbd>+<kbd>B</kbd>, then <kbd>?</kbd> at any time to open the list of active bindings.

## Start with these

| Action | Keystrokes |
| --- | --- |
| Create a tab | <kbd>Ctrl</kbd>+<kbd>B</kbd>, then <kbd>c</kbd> |
| Split right / down | <kbd>Ctrl</kbd>+<kbd>B</kbd>, then <kbd>%</kbd> / <kbd>"</kbd> |
| Move to another pane | <kbd>Ctrl</kbd>+<kbd>B</kbd>, then an arrow key or <kbd>h</kbd> <kbd>j</kbd> <kbd>k</kbd> <kbd>l</kbd> |
| Move between tabs | <kbd>Ctrl</kbd>+<kbd>B</kbd>, then <kbd>n</kbd> / <kbd>p</kbd> |
| Find an agent or pane | <kbd>Ctrl</kbd>+<kbd>B</kbd>, then <kbd>w</kbd> |
| Detach and leave agents running | <kbd>Ctrl</kbd>+<kbd>B</kbd>, then <kbd>d</kbd> |

## Pane and tab controls

| Action | Keystrokes |
| --- | --- |
| Zoom / unzoom the focused pane | <kbd>Ctrl</kbd>+<kbd>B</kbd>, then <kbd>z</kbd> |
| Close the focused pane | <kbd>Ctrl</kbd>+<kbd>B</kbd>, then <kbd>x</kbd> |
| Enter resize mode | <kbd>Ctrl</kbd>+<kbd>B</kbd>, then <kbd>r</kbd> |
| Create a tab | <kbd>Ctrl</kbd>+<kbd>B</kbd>, then <kbd>c</kbd> |
| Jump to tab 1–9 | <kbd>Ctrl</kbd>+<kbd>B</kbd>, then the tab number |
| Next / previous tab | <kbd>Ctrl</kbd>+<kbd>B</kbd>, then <kbd>n</kbd> / <kbd>p</kbd> |
| Open the overview | <kbd>Ctrl</kbd>+<kbd>B</kbd>, then <kbd>O</kbd> |
| Show or hide the sidebar | <kbd>Ctrl</kbd>+<kbd>B</kbd>, then <kbd>b</kbd> |
| Open the plugin palette | <kbd>Ctrl</kbd>+<kbd>B</kbd>, then <kbd>:</kbd> or <kbd>P</kbd> |

In resize mode, use <kbd>h</kbd>, <kbd>j</kbd>, <kbd>k</kbd>, and <kbd>l</kbd> to adjust the focused pane. <kbd>Space</kbd> enters sticky navigation mode for moving between panes. Press <kbd>Ctrl</kbd>+<kbd>B</kbd>, then <kbd>?</kbd> for the bindings available in your running version.

## Copy from pane history

Press <kbd>Ctrl</kbd>+<kbd>B</kbd>, then <kbd>[</kbd> to enter copy mode. Use the vim-style movement keys to navigate the pane history, <kbd>/</kbd> to search, <kbd>v</kbd> to start selecting, and <kbd>y</kbd> to copy. Mouse drag-selection is also available without entering copy mode.

Copy-mode navigation and selection work on the focused pane's history without stopping the process. The `?` keymap inside Hive shows the exact bindings for your version.

## Paste text and images

| Action | Keystrokes |
| --- | --- |
| Paste the last copied text | <kbd>Ctrl</kbd>+<kbd>B</kbd>, then <kbd>]</kbd> |
| Paste a clipboard image into the focused agent | <kbd>Ctrl</kbd>+<kbd>B</kbd>, then <kbd>I</kbd> |

Image paste reads PNG data from the clipboard of the machine running `hive ui` and works with remote agents too. See [Images and Terminal Graphics](/docs/use/images/) for which agents accept images and how.

## Change the bindings

Hive reads optional settings from `~/.config/hive/config.toml`. Keybindings can be customized there; see [Configuration](/docs/config/configuration/) for the config file and available options. The in-app list (<kbd>Ctrl</kbd>+<kbd>B</kbd>, then <kbd>?</kbd>) reflects the bindings active in your version and configuration.
